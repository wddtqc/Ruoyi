- **文件位置：** `ruoyi-quartz/src/main/java/com/ruoyi/quartz/task/RyTask.java`

## 📋 若依后台配置步骤

### 第二步：进入定时任务管理

**系统监控 → 定时任务**

---

### 第三步：新增定时任务

点击 **"新增"** 按钮，按照以下配置填写：

#### 📝 基础配置

| 字段           | 填写内容                                 | 说明                          |
|----------------|------------------------------------------|-------------------------------|
| 任务名称       | `农业传感器数据模拟`                     | 任意名称，便于识别             |
| 任务组名       | `DEFAULT`                                | 保持默认                       |
| 调用目标字符串 | **`ryTask.mockSensorData()`**            | ⭐ 核心配置，必须准确填写      |
| cron表达式     | `0/30 * * * * ?`                         | 每30秒执行一次                 |
| 执行策略       | `立即执行`                               | 默认即可                       |
| 是否并发       | `允许`                                   | 允许并发执行                   |
| 状态           | `正常`                                   | 启用任务                       |

#### ⚠️ 重要提示

**调用目标字符串必须填写：**
```
ryTask.mockSensorData()
```

**不要填写：**
- ❌ `mockSensorTask.pushMockData()` （旧版本，已废弃）
- ❌ `com.ruoyi.quartz.task.RyTask.mockSensorData()` （完整路径不需要）
- ❌ `RyTask.mockSensorData()` （需要小写开头的Bean名称）

## 🎨 支持的调用方式

我为你提供了3种调用方式，可以根据需要选择：

### 方式1：无参数调用（推荐）

```
ryTask.mockSensorData()
```

使用默认设备编号 `NPK-TEST-001` 进行模拟。

---

### 方式2：指定设备编号

```
ryTask.mockSensorData('NPK-TEST-002')
```

模拟指定设备的数据，设备编号为 `NPK-TEST-002`。

---

### 方式3：批量模拟多个设备

```
ryTask.mockMultiDeviceSensorData('NPK-TEST-001,NPK-TEST-002,NPK-TEST-003')
```

一次性模拟多个设备的数据，设备编号用逗号分隔。

---

## 📅 常用cron表达式

根据你的需求选择合适的执行频率：

| cron表达式           | 执行频率              | 说明                    |
|----------------------|-----------------------|-------------------------|
| `0/10 * * * * ?`     | 每10秒执行一次        | 高频测试                |
| `0/30 * * * * ?`     | 每30秒执行一次        | 推荐配置                |
| `0 * * * * ?`        | 每分钟执行一次        | 正常监控                |
| `0 0/5 * * * ?`      | 每5分钟执行一次       | 低频采集                |
| `0 0 * * * ?`        | 每小时执行一次        | 定时采集                |

## ⚠️ 常见问题排查

### Q1: 点击"执行一次"后，日志显示"MqttPublisher未初始化"

**原因：** MQTT配置未启用或连接失败

**解决方案：**
1. 检查 `application.yml` 中的MQTT配置是否正确
2. 确认MQTT Broker是否正常运行
3. 检查控制台是否有MQTT连接成功的日志

---

### Q2: 任务执行失败，提示"Bean未找到"

**原因：** 项目未正确编译

**解决方案：**
1. 在IDEA中执行 `mvn clean install`
2. 重启若依项目
3. 重新配置定时任务

---

### Q3: 调度日志显示成功，但数据库没有数据

**原因：** 数据处理逻辑可能有问题

**解决方案：**
1. 查看控制台完整日志，查找错误信息
2. 确认 `IoTDataProcessService` 是否正常工作
3. 检查设备是否在 `iot_device` 表中存在

---

### Q4: 异常数据不触发告警

**原因：** 5%概率较低，可能需要多次执行

**解决方案：**
1. 多次点击"执行一次"按钮，直到出现异常数据
2. 查看控制台是否有 "【异常数据生成】" 的日志
3. 检查 `iot_device_alert` 表是否有新记录
